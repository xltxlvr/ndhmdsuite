ndhmd4tex 변경 이력#

ndhmd4tex 0.26.1 / ndhmd2html 0.6.3#

  • 문서 일부에서만 mapping 값을 바꿨다가 되돌리는 구간 지시 추가: 한 줄짜리 <!--ndhmd mappingrule … --> 로 열고 <!--ndhmd end--> 로 닫는다. 안의 YAML 은 mappingrule: 과 같고, 닫으면 그 구간이 바꾼 키만 이전 값으로 돌아간다. 중첩·환경 안 사용 가능. 지시 줄은 블록만 끊고 문단은 나누지 않는다(ndhmd2html 은 <p> 가 나뉜다). 본문을 훑기 전에 처리되는 키(linecomment, escape_chars, external, showexam 등)는 구간에서 바꿀 수 없다. {{포함}} 파일 끝에서 자동으로 닫히지 않는다. 가이드 19.2 절.

ndhmd4tex 0.26.0 / ndhmd2html 0.6.2#

  • quotes: mixed 와 quotes_scope: cjk 추가. 여는 따옴표 다음 글자(* ~ 는 건너뜀)가 한글/한자일 때만 낫표 등 결과 문자로 바꾸고, 짝인 닫는 따옴표는 여는 쪽을 따른다. 영문 인용은 tex 따옴표(``..'')로 남는다. 이 모드에서 ' 의 단어 안 아포스트로피는 닫는 따옴표로 보지 않는다. 판정 규칙은 vpunct.py --contextual 과 같다. mixed 는 「」『』 에 cjk 를 더한 줄임말. ndhmd2html 은 변환하지 않은 쪽을 “ ” ‘ ’ 로 낸다.

ndhmd4tex 0.25.1#

  • RTLtypeset(polyglossia/babel)와 bibliography:(biblatex)를 함께 쓰면 Package biblatex Error: 'polyglossia' loaded after biblatex 가 나던 문제. 프리앰블에서 RTL 줄(polyglossia/babel)을 먼저, biblatex/kskoreanbib 와 \addbibresource 를 그 뒤에 놓는다. (사용자가 preamble: 에서 직접 biblatex 를 앞서 불렀다면 그 순서는 사용자 몫이다.)

ndhmd2html 0.6.1#

  • 옆에 ndhmd4tex.py 가 없고 확장자 없는 ndhmd4tex 만 있으면, 그것이 텍스트 스크립트일 때 불러 쓴다. 바이너리(ELF/PE/Mach-O 등, NUL 바이트, UTF-8 이 아닌 내용)는 쓰지 않고 오류를 낸다. ndhmd4tex.py 가 있으면 언제나 그쪽이 먼저이고, 있는데 가져오기가 실패한 경우에는 그 오류를 그대로 보인다. 실행 파일로 묶인 경우에는 실행 파일 옆 폴더도 찾는다.

치트시트 (ndhmd4tex 0.25.0 기준)#

  • ndhmd4tex_cheatsheet 를 0.19.2 에서 0.25.0 으로 갱신했다. 앞면은 기존 내용에 --mmd, --external, --inherit-meta 와 front matter 키(mmdoption, bibliography, RTLtypeset)를 더했고, 뒷면(확장 기능) 을 새로 만들었다: bibliography:(lang, print), 부분 컴파일·ndhmd2html, 각주 종류, ||·grid 표, external·showexam, RTLtypeset, mapping 키(quotes, tilde, wavedash, notes …), 그리고 함정·막힐 때(앞면에서 옮김).

ndhmd4tex 0.25.0 / ndhmd2html 0.6.0#

  • --inherit-meta main.md 추가: 서브 파일만 컴파일(HTML 변환)할 때 main 의 헤더를 쓴다. main 은 일반 변환과 똑같이 해석하고(setup 체인·기본 헤더 포함), 서브 파일 자신의 front matter 는 버리며, title/subtitle/author/date/maketitle/tocloft 는 상속하지 않는다. --syncinfo 의 줄 번호는 정확하게 유지된다. --pandoc/--mmd 에서는 무시한다.
  • mapping 은 main 폴더 기준으로 찾는다. main 과 폴더가 다르면 상대 경로(.bib, \input 등)에 대해 경고한다.
  • split_frontmatter() 에 lenient 인자: 깨진 YAML 도 떼어 내기만 한다.

ndhmd4tex 0.24.3#

  • bibliography: 에 print: false 를 추가했다. 문헌 목록 출력 명령을 넣지 않고 선언만 한다. \input 한 LaTeX 파일 안에 \printbibliography 가 있을 때 목록이 두 번 나오는 것을 막는다.

ndhmd2html 0.5.2 보정 (2)#

  • 사용자가 \printbibliography 를 본문에 여러 번 쓴 경우(en+ko 분할 등) HTML 에서 목록이 그 횟수만큼 중복되던 문제. HTML 은 키워드로 거르지 않으므로 전체 목록을 첫 자리에 한 번만 놓는다.

ndhmd2html 0.5.2 보정#

  • --bibharvest 가 돌리는 texlua 의 출력을 UTF-8 로 읽는다(errors="replace"). 한글 경고가 잘못된 바이트를 포함하면 UnicodeDecodeError 로 죽던 문제.
  • bbl2bibitem.lua: 수식 경고 문구를 바이트가 아니라 글자 단위로 자른다(한글이 반쪽이 되어 잘못된 UTF-8 이 나오던 원인). 한글 음절 뒤의 보이지 않는 U+F0000 표지 글리프를 수확에서 버린다.

ndhmd2html 0.5.2 / bbl2bibitem.lua (수식 복원)#

  • biber 문헌 목록의 수식($…$)을 복원한다. .bbl 필드 원문과 수확 본문의 [[MATH?]] 표지를 맞춰 채우며 추가 패스는 없다. 맞추지 못하면 ⟨수식⟩으로 남기고 경고한다.
  • bbl2bibitem.lua: 수학 글꼴 구간마다가 아니라 수식 한 덩어리($…$)마다 표지 하나를 낸다(O(n^2) 가 여러 표지로 쪼개지던 문제).
  • 수확본의 [[MATH?]] 가 ndhmd 색인 문법으로 읽혀 MATH? 색인 표지가 나오던 문제도 사라진다.

bbl2bibitem.lua (수확 누락 수정)#

  • 빈 문단이 먼저 처리되면서 다음 항목의 키를 소모해 버려, \printbibliography 를 여러 번 부르는 문서(lang: en+ko)에서 항목이 하나 빠지던 문제를 고쳤다.
  • 출력 루틴 안에서 조판되는 문단(쪽 번호 등)은 무시한다. 항목 사이에서 쪽이 넘어갈 때 쪽 번호 "1" 이 항목 키를 가로채 본문이 "1" 로 수확되던 문제.
  • 그래도 .bbl 대비 빠진 항목이 있으면 한 목록 방식으로 다시 수확해 보충한다. --single 옵션으로 직접 지정할 수도 있다.

ndhmd2html 0.5.1#

  • 문헌 목록 진단 강화: biber .bbl 에는 있으나 -thebib.tex 수확본에서 빠진 키(수확본이 낡은 경우 등)를 경고한다.
  • 문헌 목록에 없는 키를 인용하면 항상 경고하며, 해당 인용은 cite-missing 클래스(붉은색)로 표시된다.

kskoreanbib.sty 0.4 (ndhmd4tex.py 0.24.2 그대로)#

  • numeric: 논문이 아닌 kobib 항목(book, booklet …)의 제목도 『제목』 으로 찍는다. 이전에는 article 만 서식을 받아 @booklet 등의 한국어 제목이 서식 없이 나왔다. 논문은 그대로 「제목」,. 영문 항목에는 영향이 없다.

ndhmd4tex.py 0.24.2#

  • bibtex 방식의 \bibliography 에 .bib 확장자를 붙인다(\bibliography{a.bib,ref.bib}). 이전에는 확장자 없이 \bibliography{a,ref} 를 냈다. TeX Live 2023 의 bibtex 에서 확장자를 붙여도 그대로 읽히는 것을 확인했다. biblatex 의 \addbibresource 는 원래 확장자를 붙인다.

ndhmd4tex.py 0.24.1 그대로, ndhmd2html.py 0.5.0#
