CHANGELOG#

버전은 __version__ 하나로 관리한다(파일 맨 위). 수정이 있을 때마다 마지막 자리(patch)를 하나씩 올린다. 최신 항목이 위에 온다.

0.14.7#

  • 화면 언어를 English로 했을 때 [환경 설정] "컴파일·도구" 탭 등에 한글이 남던 문제 수정: 외부 도구 블록, 문헌 목록(HTML), ndhmd4tex 옵션, 조판 미리보기 --context·대기, 이 파일만(--inherit-meta), 조각 그림 종류의 라벨·체크박스·자리 표시 글·툴팁과, 조판 미리보기 패널(자동, 앞뒤 N 블록, 폭 맞춤 툴팁, 상태 문구)·메뉴 툴팁의 영어 번역을 더했다.
  • 시험: NDHMD_LANG=en 으로 환경 설정 모든 탭·미리보기 패널·메뉴를 훑어 한글이 든 글을 찾았고, 남은 것은 한자 변환 예시(국가 등)뿐이다. PageSetupDialog 는 단독 생성 시험이 실패해(샌드박스 시험 환경 문제로 보임) 훑지 못했다.

0.14.6#

  • 조판 미리보기 배율에 100% 추가. 100%는 쪽의 실제 인쇄 크기(1pt = 96/72 화면 픽셀)이고, 150%·200%·300%는 그 배율로 바뀌었다(이전엔 폭 맞춤의 배율이었음). 저장 키를 새로 써서 예전 선택은 폭 맞춤으로 돌아간다.
  • 시험: A4 PDF에서 100% = 793px, 150% = 1190px 등 확인. 여러 쪽의 크기가 달라도 그림 폭은 가장 넓은 쪽에 맞춤.

0.14.5#

  • 조판 미리보기 상태 줄에 단계별 시간 표시: 변환 0.3초 + TeX 3.5초 = 3.8초(대기 시간 제외). 시험(샌드박스, latexmk 백엔드)에서 변환 0.2초 + TeX 0.1초 = 0.3초처럼 표시됨.

0.14.4#

  • 환경설정 ▶ 컴파일·도구에 조판 미리보기 대기(1.0~5.0초, 기본 1.2초) 추가. 입력(또는 다른 문단으로 커서 이동)이 멈춘 뒤 자동 갱신을 시작하기까지의 시간이며, 1초 미만은 고를 수 없다.
  • 시험: 기본 1.2, 범위 1.0~5.0, 2.5로 저장, 범위를 벗어난 저장값(0.3)은 1.0으로 보정.

0.14.3#

  • 도움말의 구성 표기를 ndhmd4tex ≥ 0.26.5로 갱신(조판 미리보기가 --preview-at과 여러 줄 글꼴 명령 제거가 들어간 0.26.5 이상을 요구한다). 영어 번역 항목의 낡은 버전 표기(0.20.0)도 같이 바로잡아 영어 도움말에서도 번역이 적용된다.

0.14.2#

  • 환경설정 ▶ 컴파일·도구에 조판 미리보기 --context(0~10, 기본 1) 칸 추가. 패널 안의 앞뒤 N 블록과 같은 값이며 한쪽을 바꾸면 다른 쪽도 따라간다(패널 범위도 0~10으로 확대).
  • 시험: 기본값 1, 설정에서 3으로 바꾸고 저장 → 저장된 값과 열려 있는 패널 칸이 3으로 바뀜.

0.14.1#

  • 조판 미리보기: 컴파일러가 ksruncltex이면 ksruncltex로 돌리고 --max-iterations=1을 붙인다(--output-directory=·--jobname=pv 포함, 원고의 compileoption도 반영). latexmk일 때는 엔진을 직접 한 번 돌리는 기존 방식. ksruncltex를 못 찾으면 대화창 없이 상태 줄에 알림.
  • 시험: 가짜 ksruncltex로 전달 인자(--pdflatex --max-iterations=1 --output-directory=… --jobname=pv …/pv.tex)와 PDF 생성 확인. 미확인: 실제 ksruncltex의 옵션 해석·산출 위치(--output-directory=DIR 형태 가정).

0.14.0#

  • 보기 ▶ 조판 미리보기(F6, 지금 갱신 Shift+F6) 추가. 커서 자리의 앞뒤 몇 블록만 ndhmd4tex --preview-at/--context로 약식 변환·컴파일해 오른쪽 패널(떼어내기 가능)에 그림으로 보여 준다. 입력을 멈추고 1.2초 뒤 자동 갱신(끌 수 있음), 새 입력이 오면 돌던 작업을 버리고 재시작, 새 그림이 나올 때까지 이전 그림 유지. 장 파일은 최상위 헤더를 --inherit-meta로 가져온다. 저장 안 한 편집도 반영(임시 .~ndhmdWriter-tspv.md).
  • 필요: ndhmd4tex 0.26.5 이상(0.26.2는 여러 줄 글꼴 명령이 남아 오류 — 문서 글꼴 블록과 함께 쓸 때). 약식이므로 글꼴·쪽 나눔·번호·상호참조는 정확하지 않음.
  • TeX는 파이썬 스레드의 subprocess로 실행(Windows 콘솔 깜빡임 방지, 취소 가능).
  • 시험(샌드박스, pdflatex·ndhmd4tex 0.26.5): 열기 → 그림 생성, 입력 → 대기 표시 후 재갱신, 장 파일 상속, 변환 실패 문구, 떼어내기/붙이기, 임시 파일 정리; 쪽 설정·문서 글꼴 회귀 시험 통과. 미확인: 한글 문서(kotex)·LuaLaTeX 실제 속도, 맥·윈도 실제 동작, 긴 원고에서의 부담, 외부 도구 블록 원고.

0.13.6#

  • 문서 글꼴 창(font.py 1.1.1, Writer 모드)에서 Ctrl+W(맥 ⌘W)로 보내지 않고 닫을 수 있다. 원고는 바뀌지 않는다. styler 단독 실행(Writer 모드가 아닐 때)에는 단축키를 추가하지 않는다.

0.13.5#

  • 환경설정 ▶ 컴파일·도구 ▶ ndhmd4tex 옵션 추가. 한 줄로 적은 옵션(예: --encoding cp949, --config ./mapping.yaml)이 ndhmd4tex를 부르는 모든 명령(컴파일, 변환후 열기, 본문만 tex, 점검, 메타 읽기) 맨 앞에 붙는다. Writer가 붙이는 기존 옵션은 그대로 두고 뒤에 오므로 겹치면 Writer가 이긴다. ndhmd2html·--guide에는 적용 안 함.
  • 시험: --encoding cp949 로 cp949 원고를 본문만 tex 변환 → 한글 정상, 명령 순서 확인. 미확인: --config 실제 매핑 파일, 따옴표 든 값의 Windows 동작.

0.13.4#

  • 인라인 각주 ^[…]와 각주 참조 [^키]에 옅은 바탕색을 깔았다(링크색을 편집창 바탕에 16% 섞은 색 — 밝은·어두운 테마 모두 자동). 긴 인라인 각주가 본문과 한눈에 구별된다. 각주 정의 줄의 [^키]:는 예전처럼 색·이탤릭만.

  • 시험(ndhmd4tex 0.25.0): 최상위 mappingrule: ellipsis → 옵션 없이 \ldots{}, --inherit-meta와 함께면 최상위 규칙([[ELL]])이 적용됨.

0.13.1#

  • 컴파일 ▶ 본문만 tex 변환 추가: 지금 연 파일을 --default NONE으로 변환해 같은 폴더에 이름-body.tex로 남긴다(컴파일·열기 없음, 상태줄에 알림). 컴파일용 이름.tex와 섞이지 않게 이름을 달리했고, 작업공간 청소 대상도 아니다. 실패·외부 도구 안내는 기존 변환과 같다.
  • 시험(샌드박스, ndhmd4tex 0.25.0): 장 파일에서 \section{…}와 본문만 나오고 ch1.tex는 만들어지지 않음, (0.13.2에서 정정: 헤더 가져오기 옵션을 켜면 넘긴다)

0.13.0#

  • 환경설정 ▶ 이 파일만 ▶ 최상위 헤더 가져오기(기본 꺼짐) 추가. 켜면 책의 하위 파일을 이 파일만 컴파일·이 파일만 HTML로 변환할 때 --inherit-meta <최상위 원고>를 ndhmd4tex·ndhmd2html에 넘긴다. 쪽 설정·문서 글꼴 블록이 단독 컴파일에도 반영된다. 최상위 파일이거나 책이 아니면 넘기지 않는다.
  • 필요: ndhmd4tex 0.25.0, ndhmd2html 0.6.0 이상(옛 버전은 옵션을 몰라 오류). 정보창의 Powered by 표기를 0.25.0으로 갱신.
