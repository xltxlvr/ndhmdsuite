설치Installation

Windows 설치 프로그램 하나로 끝납니다. A single Windows installer does everything.

  1. ndhmdSuite_Setup.exe 설치 파일을 내려받습니다. Download the ndhmdSuite_Setup.exe installer.
  2. 실행 파일을 실행합니다. 모든 사용자(관리자 권한 필요)와 현재 사용자 설치를 모두 지원합니다. Run it. Both All Users (requires Administrator privileges) and Current User modes are supported.
  3. 이전 버전이 감지되면 설치 프로그램이 깨끗이 제거할지 먼저 묻습니다. If a previous version is detected, the installer offers to remove it cleanly first.
  4. 언어(영어 또는 한국어)를 고르고 마법사를 따라 진행합니다. Choose your language (English or Korean) and follow the setup wizard.

설치 중 자동으로 수행되는 작업Automated setup actions

  • 환경 변수: 설치 폴더를 PATH에 추가해 어느 위치에서나 명령행으로 도구를 실행할 수 있습니다.Environment variables: the install directory is appended to PATH for command-line access from anywhere.
  • 리소스 배포: 필요한 사용자 리소스를 %USERPROFILE%\ndhmd4tex\에 복사합니다.Resource deployment: user resources are copied to %USERPROFILE%\ndhmd4tex\.
  • 스크립트 초기화: ksruncltex 설치 배치 스크립트를 조용히 실행합니다.Script initialization: the ksruncltex install batch script runs silently.
  • 바로가기: ndhmdwriter.exe의 바탕화면·시작 메뉴 바로가기를 만듭니다.Shortcuts: Desktop and Start Menu shortcuts for ndhmdwriter.exe.

제거Uninstallation

  • Windows의 “설치된 앱” 또는 “프로그램 추가/제거”에서 제거합니다.Remove it from Windows “Apps & features” or “Add or Remove Programs”.
  • PATH에서 설치 폴더를 지우고 설치된 실행 파일을 삭제합니다.The install directory is removed from PATH and the binaries are deleted.
  • %USERPROFILE%\ndhmd4tex\의 사용자 파일과 설정은 필요 없다면 직접 삭제해야 합니다.Files and settings in %USERPROFILE%\ndhmd4tex\ may need to be removed manually.
